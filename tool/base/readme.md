## Overview

TBD. Base is the database + API workbench in the ClueSurf tool suite —
a graph-centric explorer for relational databases, NoSQL stores, and
HTTP APIs. Built on the same Electron + React + Tailwind platform as
`@cluesurf/term`, with the same workspace / sidebar / palette /
hotkey primitives.

See [`note/library/workbench-architecture.md`](https://github.com/cluesurf/tool/blob/make/note/library/workbench-architecture.md)
for the long-term architecture and inspirations (TablePlus, Postico,
Prisma Studio, Supabase Studio).
