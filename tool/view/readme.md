## Overview

TBD. View is the observability workbench in the ClueSurf tool suite —
logs, traces, events, metrics, and timelines as calm streams, not
enterprise dashboards. Built on the same Electron + React + Tailwind
platform as `@cluesurf/term`, with the same workspace / sidebar /
palette / hotkey primitives.

See [`note/library/workbench-architecture.md`](https://github.com/cluesurf/tool/blob/make/note/library/workbench-architecture.md)
for the long-term architecture and inspirations (Grafana, Kibana,
Datadog, Seq, Better Stack).
