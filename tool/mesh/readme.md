## Overview

TBD. Mesh is the infrastructure workbench in the ClueSurf tool suite —
a local-first, SSH-first, Docker-first view of services, containers,
queues, databases, domains, volumes, and workers. Built on the same
Electron + React + Tailwind platform as `@cluesurf/term`, with the same
workspace / sidebar / palette / hotkey primitives.

See [`note/library/workbench-architecture.md`](https://github.com/cluesurf/tool/blob/make/note/library/workbench-architecture.md)
for the long-term architecture and inspirations (Portainer, Railway,
Coolify, Dokku, Lens, OrbStack).
